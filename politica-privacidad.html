Política de privacidad de GlutenScanner

Última actualización: 9 de agosto de 2026

En resumen

GlutenScanner no tiene cuentas de usuario, ni anuncios ni seguimiento, y no recopilamos datos personales. Si decides enviar un producto, subes fotos de su envase de forma anónima y sin información personal (consulta la sección de abajo).

Cámara

La app usa la cámara para leer códigos de barras y listas de ingredientes (OCR) - ambas cosas ocurren localmente en tu teléfono y no se envían a ningún sitio - y para el envío opcional de productos, donde las fotos que haces se suben a nuestro servidor (ver abajo).

Envío de productos (opcional)

Si no se encuentra un producto, o quieres corregirlo, puedes optar por enviarlo. Haz 3 fotos (código de barras, frontal, lista de ingredientes) que se suben a nuestro servidor para que podamos añadir el producto a la base de datos en beneficio de otros usuarios.

  • Anónimo: no pedimos ni almacenamos nombre, cuenta ni datos de contacto. Los datos de ubicación (EXIF) se eliminan de las imágenes.
  • Finalidad: las imágenes se usan únicamente para crear o corregir el producto en la base de datos de productos.
  • Moderación: los envíos se revisan manualmente antes de añadirse. Las imágenes que no muestran un producto se rechazan.
  • Almacenamiento: si se rechaza un envío, todas las imágenes se eliminan de inmediato. Si se aprueba, conservamos solo la foto frontal como imagen del producto; las fotos del código de barras y de los ingredientes se eliminan.

Eliminar imágenes enviadas

Los envíos son anónimos, pero si quieres que se elimine una imagen enviada, escribe a support@glutenscanner.info con el nombre del producto o el código de barras. Entonces la localizaremos y la eliminaremos.

Historial de escaneos

Tu historial de escaneos (nombre del producto, código de barras, valoración del gluten y fecha) se guarda solo localmente en tu propio teléfono. Nunca se envía a nosotros ni a terceros, y puedes borrarlo en la app en cualquier momento.

Búsquedas en internet

Cuando escaneas un producto, el código de barras (y en algunos casos el nombre del producto) se consulta - primero en nuestra propia base de datos en glutenscanner.info y, si el producto no se encuentra allí, en: Open Food Facts, Open Products Facts, Open Beauty Facts, Kassal.app, Salling Group, UPCitemdb y DuckDuckGo (búsqueda web). No se envía ninguna información sobre ti como persona, solo el código de barras o el nombre del producto. Las políticas de privacidad de esos servicios se aplican a su tratamiento de las consultas.

Traducción

Las listas de ingredientes en otros idiomas se pueden traducir. La traducción ocurre localmente en tu teléfono (Google ML Kit) y no se envía a ningún sitio.

Informes de errores

Si la app encuentra un error técnico, nos envía automáticamente un informe de error breve y anónimo - el mensaje de error, la "traza" técnica, la versión de la app y el tipo de dispositivo (por ejemplo, Android) - para que podamos encontrarlo y corregirlo. El informe no contiene datos personales y se usa únicamente para mejorar la estabilidad de la app. No almacenamos tu dirección IP.

Fuentes de datos

Parte de los datos de productos provienen de Open Food Facts y se usan bajo la Open Database License (ODbL).

Permisos

  • Cámara: códigos de barras, listas de ingredientes (OCR) y envío de productos
  • Internet: consultar información de productos y envíos
  • Vibración: confirmación cuando se lee un código de barras
  • Estado de la red: lo usan las bibliotecas en las que se basa la app (entre ellas, Google ML Kit) para comprobar si el teléfono está conectado. No se recopila ninguna información sobre tu red

Aviso legal

GlutenScanner es una herramienta de ayuda, no un consejo médico. Las valoraciones se basan en bases de datos y búsquedas automáticas, que pueden estar incompletas o desactualizadas. Lee siempre tú mismo la lista de ingredientes del envase, especialmente en caso de enfermedad celíaca o intolerancia grave al gluten.

Contacto
